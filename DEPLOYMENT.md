# Публикация

1. Согласовать новый приём заявок с blum_leads (schema_version=2). CRM отклоняет старую анкету: нельзя обновлять две стороны с длительным перерывом.
2. Cloudflare Pages должен публиковать корень репозитория и собирать `functions/`. `_middleware.js` возвращает 410 для отключённых адресов; формы подтверждают отправку внутри main/connective.
3. Выключить функции Cloudflare Zaraz / Apps / Web Analytics, если они вставляют дополнительные теги вне репозитория: они не контролируются privacy.js.
4. Проверить новый приватный сеанс: до выбора, после «Отклонить», после «Принять», после отзыва; формы работают во всех состояниях. Внешний GTM контейнер публикуется отдельно: проверить состав тегов и фактические cookie на production.
5. Не добавлять GTM/Pixel/GA через панель Pages или HTML в обход privacy.js. Удалён noscript fallback, который обходил бы согласие. Старое blum_cookie не используется как согласие.
6. В форме только имя/телефон/email/программа/приезд/канал и отдельное согласие. Программы взяты из https://clinicblum.com/services/ (названия вариантов по длительности, без выбора диагнозов).

Изменения подготовлены в репозитории; состояние действующего Cloudflare deployment проверяется отдельно после публикации. Новые тексты политики отражают эту реализацию и перед публикацией подлежат согласованию с юристом компании.
