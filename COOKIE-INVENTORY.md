# Реестр cookie и аналогичных технологий

Состояние: реестр собственной реализации и типовых cookie подключённых сервисов, подготовленный по коду. Условные строки не означают, что cookie фактически установлен. Для полного production-перечня требуется сканирование действующего GTM, защиты Cloudflare и YouTube в каждом состоянии согласия; оно не заменяется этим справочником.

| Название cookie | Тип | Срок хранения | Поставщик |
|---|---|---|---|
| blum_consent_v2 | Технические / обязательные | 180 дней | Собственные cookie profblum.org; сохранение выбора |
| _ga | Аналитические / статистические | 2 года по умолчанию; браузер может сократить | Google Analytics 4; после согласия |
| _ga_<идентификатор> | Аналитические / статистические | 2 года по умолчанию; браузер может сократить | Google Analytics 4; после согласия |
| _fbp | Маркетинговые / рекламные | 90 дней по умолчанию | Meta Pixel; после согласия |
| _fbc | Маркетинговые / рекламные | 90 дней по умолчанию | Meta Pixel; после согласия, при переходе с fbclid |
| _gcl_au | Маркетинговые / рекламные | 90 дней по умолчанию | Google Ads / Conversion Linker; если включён соответствующий тег GTM, после согласия |
| _gcl_aw, _gcl_dc, _gcl_gb | Маркетинговые / рекламные | 90 дней по умолчанию | Google advertising / Conversion Linker; при соответствующих тегах и рекламных переходах, после согласия |
| YSC | Маркетинговые / рекламные | Сессионный | YouTube; после согласия и запуска встроенного видео |
| VISITOR_INFO1_LIVE | Маркетинговые / рекламные | 180 дней по умолчанию | YouTube; после согласия и запуска встроенного видео |
| VISITOR_PRIVACY_METADATA | Технические / обязательные для встроенного сервиса | 180 дней по умолчанию | YouTube; только после согласия на загрузку сервиса |
| __cf_bm | Технические / обязательные | 30 минут бездействия | Cloudflare Bot Management; только если включена соответствующая защита |
| cf_clearance | Технические / обязательные | Срок Challenge Passage в настройках Cloudflare | Cloudflare; при прохождении проверки |
| CF_Authorization | Технические / обязательные | Срок сессии приложения в Cloudflare Access | Cloudflare Access; только административный поддомен leads.profblum.org |

Google Tag Manager сам не является именем cookie: cookie задаются тегами контейнера GTM-T7GP6RK8. Внешний контейнер может меняться независимо от GitHub; окончательный перечень должен соответствовать опубликованной версии контейнера. Блокировка загрузки контейнера действует до согласия для всех его тегов.

В коде нет отдельного session_id, cookie формы, Cookiebot или Cloudflare Web Analytics. Старый blum_cookie был localStorage, а не cookie; он не учитывается как согласие новой версии. Текст жалобы и имя программы не передаются событиям трекеров из contact.js. IP/заголовки могут обрабатываться самой инфраструктурой без установки cookie.

При отзыве отключается дальнейшая загрузка трекеров, удаляются доступные first-party _ga/_gid/_gat/_gcl/_fbp/_fbc для текущего хоста и родительского домена, страница перезагружается. Third-party cookie Google/Meta/YouTube очищаются пользователем в браузере; сайт не может удалить их через document.cookie.

Приёмочная проверка: новый профиль; обе страницы до выбора/отказ/согласие/отзыв; рекламный переход с fbclid и gclid; запуск каждого видео; отдельно вход сотрудников на leads. Сохранить имя, domain, path, expires/max-age и категорию каждого фактически установленного cookie, включая HttpOnly через инструменты браузера. Секретные значения cookie и access-токены в отчёт не включать.
